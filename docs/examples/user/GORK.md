# My rules, for every project

gork sends ~/.gork/GORK.md (_gork\GORK.md on DOS and Windows) before the
project's own GORK.md, in every directory it runs in. Put here what holds
wherever you work; what one project needs goes in that project's GORK.md.

- Answer briefly. Say what you changed and what you could not do.
- Read a file before you edit it, and change only what the task needs.
- Ask before deleting files or running anything that cannot be undone.
- Run the project's tests after a change, if it has any, and say whether
  they passed.
- Do not commit or push unless I ask.
